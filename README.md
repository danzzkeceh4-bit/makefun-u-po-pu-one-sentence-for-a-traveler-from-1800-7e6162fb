A [make.fun](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) bounty entry: one sentence, at most 200 characters, explaining the modern internet to a time traveler who has just stepped out of the year 1800 — built only from things a person from 1800 already knows.

## The sentence

> Imagine every library in the world joined by roads of lightning, so any letter you write arrives anywhere before the ink dries.

127 characters. No word coined after 1800: libraries, roads, lightning, letters, ink. Every library joined together is the web of knowledge; a letter arriving before the ink dries is its speed.

## How it works

`main.py` writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline, and validates it is 1–200 characters.

```sh
python3 main.py
```
